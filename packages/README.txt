PACKAGE DOCUMENTS
=================

Each service page has a "Packages" section that links to a PDF in this folder.
The links are already wired up. Drop the PDFs in here with these exact
filenames and they will start working immediately. No code changes needed.

  stationery.html  ->  packages/stationery-signage-packages.pdf
  floral.html      ->  packages/floral-decor-styling-packages.pdf
  planning.html    ->  packages/planning-coordination-packages.pdf

Notes
-----
- Filenames are case-sensitive on GitHub Pages. Use lowercase exactly as above.
- Until a PDF is added, its download link will return a 404. If you would
  rather hide a package card than show a dead link, delete that <a class=
  "package-card"> block from the relevant page.
- Keep the same filename when you update a document so the links never break.
